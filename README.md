Step 1. 미션 읽어보고 구상하기
```
미션을 읽어보고 자동화 업무를 도와주는 툴에 대해서 궁금증이 생겼다.
AI 두 모델(Claude Sonnet 5, Gemini pro)에 물어보니 Make와 Zapier 이 두 종류의 툴을 소개해주었다.
하지만 더 나은 모델이 없는지 Cladue Sonnet 5에 문의하니 n8n이란 은 서버 구축만 되면 무료라는 점을 알게 되었다.
좀 더 자세히 알아보니 n8n 로컬, n8n 셀프호스팅, n8n cloud 세 종류가 있어서 make, zapier의 상위 수준에서 사용하는 게 적절할 것으로 생각된다.
더 나아가 Zapier는 조건 분기(Router) 사용에 있어서 무료 플랜으로 제한되는 사항이 있는 것으로 보인다.

| 선택지 | 서버 관리 | 비용 | 상시 자동화 가능 여부 |
|---|---|---|---|
| n8n 로컬(npx) | 내가 직접(컴퓨터를 계속 켜둬야) | 0원 | ❌ 사실상 불가 |
| n8n 셀프호스팅(저가 VPS) | 내가 세팅, 이후 자동 운영 | 월 3~7천원대 | ✅ 가능 |
| n8n Cloud | n8n이 대신 | 트라이얼 후 월 2~3만원대~ | ✅ 가능 |
| **Make** | Make가 대신 | **무료(월 1,000 Ops까지)** | ✅ 가능 |
| Zapier | Zapier가 대신 | **무료(월 100 Tasks까지)** | ✅ 가능 |
```
